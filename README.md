# Dostlar Hanesi

ReactJS ile CRUD + LocalStorage uygulaması.  
Kitaplar, Filmler ve Diziler için ekleme, listeleme, güncelleme, silme ve favorilere ekleme özellikleri içerir.  
Yorum şablonları, kendi yorum alanı, tarih-saat kaydı ve yıldızlı puanlama sistemi eklenmiştir.

## 🚀 Özellikler
- Kitap, film ve dizi ekleme
- Listeleme, güncelleme ve silme
- Favorilere ekleme
- Hazır yorum şablonları + kendi yorum yazma
- Tarih ve saat kaydı
- Yıldızlı puanlama sistemi
- LocalStorage ile veri kalıcılığı

## 🛠️ Kullanılan Teknolojiler
- ReactJS
- Pure CSS
- LocalStorage
- Netlify (deploy için)
